# Vible · 비주얼 바이블

말씀을 읽다, 장면을 만나다.

창세기와 신약 27권의 **310장 · 9,490절 · 2,392개 맥락과 고유 이미지**를 연결한 웹앱입니다. 전체 장면의 그림 제작과 검수를 마쳤습니다. 상단에서 성경을 선택합니다. 본문을 읽어 내려가면 그림이 맥락에 맞춰 바뀝니다. 각 책의 첫 장부터 마지막 장까지 하나의 연속 스크롤로 이어지며, 장 사이에 클릭이 필요하지 않습니다. 본문은 그림 위에 오버레이되며 데스크톱은 왼쪽, 모바일은 아래에 배치됩니다. 전체 흐름, 장면 지도와 검색, 글자 크기 변경, 그림 몰입 모드, 모바일 읽기와 읽던 위치 저장을 지원합니다.

## 말씀 검색

책 이름 옆 입력창에 검색어를 쓰고 Enter 또는 돋보기를 누릅니다. ⌘K / Ctrl+K도 지원합니다. 모바일에서는 입력창을 누르면 같은 줄 전체로 넓어지고, 입력창 밖을 누르면 원래 크기로 돌아옵니다. 단어·문구, `요 3:16`, `고전 13:4–7` 같은 주소를 지원합니다. 전체 성경 또는 현재 책에서 검색하고, 결과를 누르면 해당 절과 장면으로 이동합니다. 검색은 브라우저에서 수행하며 외부 검색 API를 호출하지 않습니다. 검색 파일은 처음 열 때 내려받고 이후 오프라인에서도 재사용합니다. 한국어는 28권, 영·일·중은 번역이 제공되는 4권씩 검색합니다. 빌드가 언어별 색인을 생성하며 로컬 실행도 빌드를 먼저 수행합니다.

## Vercel 배포

1. Vercel에서 **Add New → Project**를 선택합니다.
2. GitHub의 **hunkim/vible**을 Import합니다.
3. Root Directory는 저장소 루트(`./`)로 둡니다.
4. Deploy를 누릅니다.

`vercel.json`에 Framework: Other, Build Command: `npm run build`, Output Directory: `dist`를 설정했습니다. 별도 환경변수나 API 키가 필요하지 않습니다. 빌드에는 외부 패키지 설치가 필요하지 않습니다. 설정 설명: https://vercel.com/docs/project-configuration

성경 본문은 원본 그대로 보존했습니다. 장면 구분과 제목은 편집 판단이며, 그림은 역사 사진이 아닌 시각적 해석입니다. 비유·환상·설교 중 과거 이야기를 그린 장면은 앱의 설명에서 구분합니다. 사도행전의 `(없음)` 및 `[25절과 같음]` 표기도 보존했습니다. 5:3–4와 7:53–8:11의 괄호도 유지했습니다. 목회자나 성서학자의 장면별 최종 감수는 별도 단계입니다.

그림은 내장 image_gen으로 최대 10개씩 병렬 생성했습니다. 자연광과 대형 포맷 역사 영화 톤을 사용하며 그림 안에는 장식 글씨를 넣지 않았습니다. `image-plan.json`, `acts-image-plan.json`, `romans-image-plan.json`, `revelation-image-plan.json`, `genesis-image-plan.json`은 각 책의 전체 프롬프트, `continuity-edits.json`은 8개 장면 수정 기록, `image-overrides.json`은 최종 그림 선택을 보존합니다. 생성 원본의 개인 컴퓨터 경로는 포함하지 않습니다.

`python3 build-data.py`와 `python3 build-acts.py`로 각 책의 본문과 기획을 다시 만들 수 있습니다. 사도행전 구분 기획은 `acts-outline.txt`에 보존했습니다. `?book=acts`로 사도행전을 바로 열 수 있습니다. `?preview=1`은 확인 중 읽던 위치 저장을 바꾸지 않습니다.


## 설치·묵상·공유

서비스 도메인은 https://vible.now/ 입니다. 상단 **설치** 버튼으로 설치할 수 있습니다. 브라우저가 설치 창을 지원하지 않으면 홈 화면 추가 안내를 보여 줍니다. 웹앱 매니페스트와 서비스워커를 포함하며, 아홉 책의 전체 본문 및 최근 열어 본 그림 최대 60장을 오프라인 캐시합니다. 전체 그림을 미리 내려받지 않으므로 아직 열지 않은 그림은 인터넷 연결이 필요합니다.

본문을 선택하거나 절 번호를 누르면 선택한 글 바로 위에 하이라이트·노트·URL 공유·카드 공유 아이콘이 나타납니다. 위쪽 공간이 부족하면 아래쪽에 표시하고, 읽기 스크롤에 따라 위치를 맞춥니다. 노트와 하이라이트는 해당 브라우저 기기의 localStorage에 저장하며 서버로 전송하지 않습니다. 다른 기기와 동기화되지 않습니다. 공유 카드는 기본 1200×675 가로형 PNG로, 긴 구절은 높이를 늘려, 말씀과 묵상, vible.now를 이미지에 합성합니다. 이미지 공유와 링크 공유를 분리해 메신저·SNS를 기기의 네이티브 공유 창에서 선택할 수 있습니다. 이미지는 PNG 파일 자체를 전달하고, 링크는 선택한 말씀 위치의 URL을 전달합니다. 파일 공유 미지원 브라우저에서는 이미지 저장 후 사진 첨부를, 링크 공유 미지원 브라우저에서는 URL 복사를 제공합니다. 복사 권한이 없어도 표시된 URL을 직접 선택해 복사할 수 있습니다. 말씀 링크는 `?book=acts&chapter=16&verse=31` 형식입니다. 너무 긴 선택은 카드에 맞도록 줄여 달라는 안내를 표시하며 본문을 임의로 생략하지 않습니다.

앱 아이콘은 내장 이미지 도구로 제작했습니다. 열린 책에서 예수님이 걸어 나오는 모습으로 말씀이 시각적으로 다가오는 의미를 표현합니다. 원본과 192/512px, iOS 180px, maskable 아이콘을 `icons/`에 보존합니다. 사도행전 추가 분할은 `acts-extra-scenes.json`에 기록했습니다.

## 요한복음 그림 구도 개정

요한복음 4:1–42의 10장(27–36번)을 내장 image_gen으로 새로 그렸습니다. 주요 인물과 소품은 오른쪽, 왼쪽은 말씀을 위한 배경으로 배치했습니다. 우물 밖의 발과 좌석, 손·그릇·물의 관계를 확인하고 물동이 장면은 한 번 더 수정했습니다. 전체 196장용 프롬프트에는 같은 구도·물리적 검수 기준을 반영했습니다. 나머지 186장의 실제 이미지는 기존 버전을 유지합니다. 생성 기록은 `john-right-redraws.json`, 제작·검수 기준은 `john-image-guidelines.md`입니다.

## 로마서

`?book=romans`로 로마서를 엽니다. 16장 433절을 96개의 논증 맥락으로 나누었으며 원문과 16:24의 `(없음)`을 보존했습니다. 자연광 역사 영화 톤과 왼쪽 말씀·오른쪽 그림 구도를 이어가되 모든 그림을 로마서용으로 새로 생성합니다. 편지의 논증은 법정·선물·세례·가족·감람나무·공동 식탁 등의 시각적 비유로 표현하고, 과거 회상과 편지 인물의 편집 장면을 앱 설명에서 구분합니다.

`python3 build-romans.py`로 본문과 기획을 재생성합니다. `romans-outline.txt`는 맥락 구분, `romans-image-plan.json`은 기획 프롬프트, `romans-generation.json`은 실제 사용 프롬프트와 생성 원본 ID, `romans-overrides.json`은 수정본 선택, `romans-production.md`는 제작·검수 기준과 완료 결과를 보존합니다. 로마서에서도 장면 지도·검색·노트·하이라이트·구절 및 이미지 공유·읽던 위치 저장·오프라인 본문 읽기를 사용할 수 있습니다.

## 요한계시록

`?book=revelation`로 엽니다. 22장 404절을 96개 맥락으로 나눕니다. 환상과 상징을 자유롭게 시각화하면서 신실함·경배·심판·소망의 흐름을 따르고, 모든 세부를 확정하거나 현대 인물·국가·기술 및 종말의 시간표로 대응시키지 않습니다. 기존 영화 톤과 말씀을 위한 오른쪽 그림 구도를 유지합니다.

`python3 build-revelation.py`로 원문과 기획을 대조해 데이터와 프롬프트를 재생성합니다. `revelation-outline.txt`, `revelation-image-plan.json`, `revelation-generation.json`, `revelation-production.md`에 맥락·기획·실제 생성·검수 기록을 보존합니다. 다른 책과 같은 읽기·검색·장면 지도·노트·공유·오프라인 기능을 사용합니다.


## 창세기

`?book=genesis&lang=ko`로 엽니다. 50장 1,533절을 272개 맥락으로 나누어 창조에서 요셉의 마지막까지 이어 읽습니다. 기존 자연광 역사 영화 톤에 웅장한 풍경과 가까운 인물의 감정을 교차해, 창조·언약·기다림·고난·책임·화해의 흐름을 시각화합니다. 창조와 족보는 편집 시각화로, 꿈과 시적 축복은 실제 사건과 구분합니다.

`python3 build-genesis.py`로 원문과 기획을 대조해 데이터와 프롬프트를 재생성합니다. `genesis-outline.txt`, `genesis-image-plan.json`, `genesis-generation.json`, `genesis-production.md`가 맥락·기획·생성·검수 기록입니다. 사용자 제보로 44:18–29의 242번 유다 장면에서 중복된 오른손을 수정했으며, 원래 표정과 궁전의 빛을 유지한 v2를 데스크톱·모바일에서 확인했습니다. 한국어 개역한글로 제공하며 다른 책의 읽기·장면 지도·검색·노트·공유·오프라인 기능과 연결합니다.

## 마태·마가·누가복음

세 복음서의 개역한글 본문 68장, 2,900절을 모두 읽고 각 책의 서술 순서에 맞춰 장면을 구성했습니다. 마태복음은 28장 1,071절 218개 장면, 마가복음은 16장 678절 134개 장면, 누가복음은 24장 1,151절 250개 장면입니다. 내장 image_gen으로 최대 10개씩 동시 생성한 새 이미지 602장을 완성했습니다. 전체 장면을 전수 검수하고 핵심 107개 장면을 확대해 확인했으며, 14개 장면의 수정본을 최종 반영했습니다. 제작·검수 결과는 `gospels-production.json`과 `gospels-quality-audit.json`에 기록합니다.

마태의 약속과 가르침, 마가의 빠른 만남과 섬김, 누가의 환대와 돌아온 사람들을 각 복음서의 흐름으로 시각화합니다. 평행 본문에서 인물 수나 장소, 순서가 다른 부분을 합치지 않습니다. 마태의 두 맹인, 마가의 바디매오, 누가의 여리고에 다가가는 맹인을 구분하며, 누가의 백부장은 보낸 사람들을 통해 간청합니다. 동방박사의 집과 목자의 구유, 엠마오에서 떡을 떼어 알아본 순간과 뒤의 예루살렘 인사도 구분합니다. 꿈·비유·족보는 실제 현장의 사건과 구분하며, 괄호와 `(없음)` 표기를 원본 그대로 보존합니다.

Take Heart 제작 기록과 승인된 인물 참조를 확인해 성킴과 승인된 여성 캐릭터를 32개의 치유·회복·만남 장면에 배역으로 사용했습니다. 이는 성경 속 인물의 실제 외모나 성킴의 실제 삶에 대한 주장이 아닙니다. 예수님에게 이 얼굴을 사용하지 않으며, 예수님의 얼굴은 어린 시절을 포함해 드러내지 않습니다. 참조 사진은 공개 앱 빌드에 포함하지 않습니다. 날개가 있는 천사는 양쪽 날개가 등 위쪽에서 시작하는지 확인합니다.

`python3 build-gospels.py matthew mark luke`로 원본 본문과 기획을 다시 대조합니다. 각 책의 `*-outline.txt`, `*-image-plan.json`, `*-generation.json`, 수정이 있을 경우 `*-overrides.json`에 맥락·프롬프트·실제 생성·최종 선택을 보존합니다. `?book=matthew&lang=ko`, `?book=mark&lang=ko`, `?book=luke&lang=ko`로 각 책을 엽니다. 본문 대조 출처는 [마태복음](https://www.bible.com/ko/bible/88/MAT.1.KRV), [마가복음](https://www.bible.com/ko/bible/88/MRK.1.KRV), [누가복음](https://www.bible.com/ko/bible/88/LUK.1.KRV)입니다.

## 고린도전서와 나머지 신약 제작

고린도전·후서부터 유다서까지 20권의 **105장·2,334절·새 이미지 871장**을 완성했습니다. 개역한글 원본 본문과 절 경계를 그대로 보존하고, 맥락이 바뀔 때마다 별도의 큰 그림을 연결했습니다. 전체 그림을 전수 검수했으며 성킴남·성킴여·연경이 등장하는 170개 장면을 모두 확대 확인했습니다. 천사 관련 11개 장면의 맥락과 날개 연결을 확인하고, 손 중복·거울 반사·작은 잡티가 있던 8개 장면의 수정본을 반영했습니다. 모든 책의 PC·모바일 읽기, 장 이동, 구절 이미지 카드와 공유 링크를 검증했습니다. 최종 근거는 `epistles-quality-audit.json`에 보존합니다.

`epistles-production.json`과 각 책의 `*-generation.json`에 저장 완료 수와 생성 이력을 기록합니다. 내장 image_gen으로 최대 10개씩 병렬 생성하고 실패하거나 오래 대기하는 요청은 재시도했습니다. 수정 전 원본도 보존합니다. 현재 `partial-release.json`은 비어 있으며 871개 새 장면 모두 실제 이미지로 제공됩니다. `python3 review/epistles-progress.py`로 저장된 파일과 기획을 대조해 진행 수를 갱신합니다.

중단 후에는 `python3 review/epistles-pending.py`로 아직 저장되지 않은 장면만 찾습니다. `python3 review/gospels-contact-sheet.py 책ID`로 검수 시트를 갱신하고, `python3 review/epistles-review-ready.py 책ID`로 실제 파일이 준비된 미검수 장면과 참조 얼굴 확대 검수 대상을 확인합니다. `review/*-qa-state.json`에 검수와 수정 대상을 보존하며, 각 책의 검수·본문 대조를 마친 뒤 `python3 review/release-epistles.py 책ID`로 로컬 앱에서 그림을 사용할 수 있게 합니다. 전체 완료는 `python3 review/check-epistles-complete.py`의 실제 파일·중복·본문·시각 검수·브라우저 검증 결과로 확인합니다.

`npm run check`는 공유·설치·언어·모바일·장면 이동 바·부분 공개 경계와 본문 보존 검사를 실행하고 전체 앱을 빌드합니다. `node check-offline.mjs`는 전체 본문과 제작 중 배경의 오프라인 동작을 확인합니다.
