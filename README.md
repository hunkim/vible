# Vible · 비주얼 바이블

말씀을 읽다, 장면을 만나다.

요한복음 **21장 · 879절 · 196개 맥락 장면**과 사도행전 **28장 · 1,007절 · 259개 맥락 장면**을 담은 웹앱입니다. 상단에서 성경을 선택합니다. 본문을 읽어 내려가면 그림이 맥락에 맞춰 바뀝니다. 각 책의 첫 장부터 마지막 장까지 하나의 연속 스크롤로 이어지며, 장 사이에 클릭이 필요하지 않습니다. 본문은 그림 위에 오버레이되며 데스크톱은 왼쪽, 모바일은 아래에 배치됩니다. 전체 흐름, 장면 지도와 검색, 글자 크기 변경, 그림 몰입 모드, 모바일 읽기와 읽던 위치 저장을 지원합니다.

## Vercel 배포

1. Vercel에서 **Add New → Project**를 선택합니다.
2. GitHub의 **hunkim/vible**을 Import합니다.
3. Root Directory는 저장소 루트(`./`)로 둡니다.
4. Deploy를 누릅니다.

`vercel.json`에 Framework: Other, Build Command: `npm run build`, Output Directory: `dist`를 설정했습니다. 별도 환경변수나 API 키가 필요하지 않습니다. 빌드에는 외부 패키지 설치가 필요하지 않습니다. 설정 설명: https://vercel.com/docs/project-configuration

## 로컬 실행

```sh
npm run dev
```

http://127.0.0.1:4174/ 에서 엽니다.

```sh
npm run check
python3 check.py john
python3 check.py acts
node check-http.mjs
```

`check.py`에는 Python Pillow가 필요합니다. 빌드는 Node.js 기본 라이브러리만 사용합니다. 빌드는 원본 본문과 절 번호의 일치, 두 책의 49장 범위, 455개 그림 파일을 확인한 뒤 실제 사용하는 그림만 `dist/`에 담습니다.

## 본문과 그림

성경전서 개역한글판 © 대한성서공회 1961.

- 전자 본문 데이터: https://github.com/yuhwan/Bible-krv
- 사도행전 본문 대조: https://www.bible.com/ko/bible/88/ACT.1.KRV
- 본문 대조: https://www.bible.com/ko/bible/88/JHN.1.KRV
- 역본 사용 안내: https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5
- 사도행전 구조 참고: https://bibleproject.com/guides/book-of-acts/
- 구조 참고: https://bibleproject.com/guides/book-of-john/

성경 본문은 원본 그대로 보존했습니다. 장면 구분과 제목은 편집 판단이며, 그림은 역사 사진이 아닌 시각적 해석입니다. 비유·환상·설교 중 과거 이야기를 그린 장면은 앱의 설명에서 구분합니다. 사도행전의 `(없음)` 및 `[25절과 같음]` 표기도 보존했습니다. 5:3–4와 7:53–8:11의 괄호도 유지했습니다. 목회자나 성서학자의 장면별 최종 감수는 별도 단계입니다.

그림은 내장 image_gen으로 최대 10개씩 병렬 생성했습니다. 자연광과 대형 포맷 역사 영화 톤을 사용하며 그림 안에는 장식 글씨를 넣지 않았습니다. `image-plan.json`과 `acts-image-plan.json`은 각 책의 전체 프롬프트, `continuity-edits.json`은 8개 장면 수정 기록, `image-overrides.json`은 최종 그림 선택을 보존합니다. 생성 원본의 개인 컴퓨터 경로는 포함하지 않습니다.

`python3 build-data.py`와 `python3 build-acts.py`로 각 책의 본문과 기획을 다시 만들 수 있습니다. 사도행전 구분 기획은 `acts-outline.txt`에 보존했습니다. `?book=acts`로 사도행전을 바로 열 수 있습니다. `?preview=1`은 확인 중 읽던 위치 저장을 바꾸지 않습니다.


## 설치·묵상·공유

서비스 도메인은 https://vible.now/ 입니다. 상단은 로고·책 선택·이전 장·장 선택·다음 장을 한 줄로 표시합니다. 햄버거 메뉴에서 읽기·전체 흐름·장면 지도·나의 노트 및 하이라이트를 엽니다. 메뉴의 **Vible 앱 설치** 버튼을 눌렀을 때만 큰 설치 화면을 표시하며 자동으로 띄우지 않습니다. 설치 가능한 브라우저에서는 **지금 설치하기**로 기기 설치 창을 엽니다. 브라우저가 설치 창을 지원하지 않으면 홈 화면 추가 안내를 보여 줍니다. 웹앱 매니페스트와 서비스워커를 포함하며, 두 책의 전체 본문 및 최근 열어 본 그림 최대 60장을 오프라인 캐시합니다. 전체 그림을 미리 내려받지 않으므로 아직 열지 않은 그림은 인터넷 연결이 필요합니다.

본문을 선택하거나 절 번호를 누르면 선택한 글 바로 위에 하이라이트·노트·URL 공유·카드 공유 아이콘이 나타납니다. 위쪽 공간이 부족하면 아래쪽에 표시하고, 읽기 스크롤에 따라 위치를 맞춥니다. 노트와 하이라이트는 해당 브라우저 기기의 localStorage에 저장하며 서버로 전송하지 않습니다. 다른 기기와 동기화되지 않습니다. 공유 카드는 1080×1350 PNG로, 말씀과 묵상, vible.now를 이미지에 합성합니다. 이미지 공유와 링크 공유를 분리해 메신저·SNS를 기기의 네이티브 공유 창에서 선택할 수 있습니다. 이미지는 PNG 파일 자체를 전달하고, 링크는 선택한 말씀 위치의 URL을 전달합니다. 파일 공유 미지원 브라우저에서는 이미지 저장 후 사진 첨부를, 링크 공유 미지원 브라우저에서는 URL 복사를 제공합니다. 복사 권한이 없어도 표시된 URL을 직접 선택해 복사할 수 있습니다. 말씀 링크는 `?book=acts&chapter=16&verse=31` 형식입니다. 너무 긴 선택은 카드에 맞도록 줄여 달라는 안내를 표시하며 본문을 임의로 생략하지 않습니다.

앱 아이콘은 내장 이미지 도구로 제작했습니다. 열린 책에서 예수님이 걸어 나오는 모습으로 말씀이 시각적으로 다가오는 의미를 표현합니다. 원본과 192/512px, iOS 180px, maskable 아이콘을 `icons/`에 보존합니다. 사도행전 추가 분할은 `acts-extra-scenes.json`에 기록했습니다.
